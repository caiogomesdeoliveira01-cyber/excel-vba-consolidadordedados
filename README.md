# 📊 Consolidador de Planilhas Excel VBA

Ferramenta desenvolvida em VBA para consolidar dados de múltiplos arquivos Excel de forma automatizada, rápida e flexível.

---

## 🚀 Funcionalidades

- Consolidação de múltiplos arquivos Excel
- Seleção de planilhas por:
  - Primeira planilha
  - Nome específico
  - Ordem
  - Todas
- Validação de dados
- Remoção de duplicadas
- Tratamento de cabeçalho
- Inclusão de colunas:
  - Nome do arquivo
  - Nome da planilha
